# Frontend

TypeScript, CSS, and Ant Design are the core. Pick the framework by project type:

| Project type | Stack |
| --- | --- |
| SaaS, dashboard, admin | React + Vite |
| Portfolio, landing page, content | Astro + React |
| SSR, dynamic SEO, Next-specific needs | Next.js |

Do not default to Next.js when the project needs no SSR, server components, or Next-specific capability.

| Page | Covers |
| --- | --- |

| [React + Vite + Ant Design](./react-vite-antd.md) | Layout, components, theming, Vite, performance |
| [State and data fetching](./state-and-data-fetching.md) | Local, server, and shared state |
